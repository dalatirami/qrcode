# Dalati QR Tools 🔳

**Dalati QR Tools** is a secure, 100% client-side web application designed to generate, customize, and decode QR codes instantly in your browser. Built with modern web technologies, it ensures absolute privacy by processing all data locally without any server uploads.

🌐 **Live Application:** [https://dalati.org/qrcode/index.html](https://dalati.org/qrcode/index.html)

This software was programmed and developed by Rami Al-Dalati (Software Developer, Digital Content Creator, and owner of the **Dalati English** platform). ### Key Features 🚀

- **100% Client-Side & Secure**: All QR generation and image decoding occur entirely in your local browser. No data or images are ever uploaded to a server, guaranteeing absolute privacy.
- **Smart Data Templates**: Pre-built, optimized input fields for Text/URLs, Wi-Fi Networks, Crypto Addresses, and vCards.
- **Advanced Customization**: Complete control over colors, dot shapes, corner styles, and Error Correction Levels (L, M, Q, H).
- **Center Logo Integration**: Seamlessly upload and embed custom logos into the center of your QR codes.
- **High-Resolution Export**: Download pristine, print-ready QR codes in PNG, JPG, SVG, or WEBP formats (up to 2500x2500 pixels).
- **Live Camera Scanner**: Instantly decode QR codes using your device's webcam or smartphone camera, alongside drag-and-drop support.
- **Bulk Processing**: Save time by generating multiple QR codes (up to 10 items) at once from a simple text list.
- **Premium True-Dark UI**: A carefully crafted, deep purple (`#1B011E`) and rich burnt orange (`#C26217`) dark mode interface designed to reduce eye strain and provide a modern UX, fully responsive for both mobile and desktop.

### 🛠️ Quick Start & Local Setup

Since Dalati QR Tools is a vanilla HTML/CSS/JS web application, no complex installation or backend server is required.

**To use the live version:**
Simply visit [https://rami.dalati.org/qrcode](https://rami.dalati.org/qrcode) on any modern web browser.

**To run locally for development:**

1. Clone or download this repository to your local machine.
2. Open the project folder.
3. Simply double-click `index.html` to open it in your browser, or use a local development server (like VS Code Live Server) for a better experience.
